## Cài đặt

- GitHub: https://github.com/
- Git: https://git-scm.com/
## Tạo tài khoản GitHub
Đăng ký tài khoản trên GitHub và đăng nhập
## Các bước đẩy bài lên GitHub
### B1. Mở Terminal trong VS Code

```bash
git add .
```

### B2. Commit

```bash
git commit -m "Nội dung"
```

### B3. Đồng bộ từ GitHub
```bash
git pull
```

### B4. Đẩy lên GitHub

```bash
git push
```
